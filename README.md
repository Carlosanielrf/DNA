# DNA Explorer

Web app interativa para explorar a dupla hélice do ADN humano.

## Funcionalidades

- **Orientação responsiva**: hélice na vertical em mobile, na horizontal em desktop
- **Pan e zoom**: arrastar, pinça, scroll do rato e botões + / −
- **Factos ao clicar**: esferas e degraus revelam bases, esqueleto, genes e mais
- **Fundo fluido**: gradiente animado com partículas e bokeh suaves

## Desenvolvimento

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```
